# extension/background.js as released in 0.5.28

An unmodified copy of `extension/background.js` from extension 0.5.28 (commit
`16297fe`), the last version before archives record original images. Tests in
`extension/background.test.js` run it against archives written by the current
version to prove what an older extension really does to them, and that the
current version notices (downgrade detection). It is never loaded by the
extension. Do not edit it.
